# 🧸 Petit Plushiê — Feitas para Abraçar

Uma plataforma de e-commerce encantadora, moderna e responsiva voltada para a venda de pelúcias premium e colecionáveis. O projeto foi desenvolvido utilizando **Next.js** para o front-end, combinando alta performance (SSR/SSG), uma paleta de cores acolhedora, tipografia elegante e componentes interativos de última geração como o carrossel do **Shadcn/ui**.

---

## 🧭 Sobre o Projeto

A **Petit Plushiê** nasceu com o propósito de transformar qualquer momento em algo especial através de pelúcias macias, fofas e cheias de amor. A interface foi cuidadosamente projetada para transmitir conforto, ternura e uma experiência de compra fluida e segura para o usuário.

### 🌟 Diferenciais da Loja:
* **Toque Incrivelmente Macio:** Foco na experiência tátil e na qualidade sensorial dos produtos apresentados.
* **Materiais Premium:** Selecionados com carinho para garantir durabilidade e segurança (perfeito para recém-nascidos e colecionadores).
* **Design Encantador:** Curadoria de formatos lúdicos e estéticas afetivas (como dinossauros, polvos, coelhos e abacates).
* **Companheiros para Todas as Horas:** Criação de memórias afetivas e vínculos especiais.

---

## 🎨 Identidade Visual e UI/UX

O design reflete um ambiente acolhedor, sofisticado e lúdico através de escolhas estéticas bem planejadas:
* **Paleta de Cores:** Tons pastéis, beges e rosados suaves (`#faf8f5`, `#fdfbf7`), complementados por um marrom acentuado elegante nos botões e cabeçalhos primários para excelente contraste e acessibilidade.
* **Tipografia:** Combinação harmoniosa de fontes serifadas para títulos (passando uma ideia de produto artesanal e premium) e fontes sans-serif limpas para descrições e preços, garantindo leitura escaneável.
* **Componentes Premium:** Utilização de sombras suaves, bordas arredondadas (`rounded-lg` / `rounded-xl`) e estados de *hover* interativos que enriquecem a experiência do usuário.

---

## 🛠️ Tecnologias Utilizadas

O ecossistema de ferramentas escolhido garante escalabilidade, performance e otimização para motores de busca (SEO):

* **Next.js (App Router):** Framework React para renderização híbrida rápida e roteamento otimizado.
* **React.js:** Biblioteca base para a construção da interface modularizada em componentes.
* **Tailwind CSS:** Framework utilitário para uma estilização rápida, responsiva e altamente customizável.
* **Shadcn/ui:** Componentes de interface primitivos, acessíveis (Radix UI) e customizados — com destaque especial para o **Carrossel** de produtos em destaque e banners institucionais.
* **Lucide React / Ícones Customizados:** Ícones minimalistas para sacola de compras, busca, perfil de usuário e selos de benefícios.

---

## 🗂️ Funcionalidades Implementadas no Front-end

1. **Cabeçalho Institucional (Navbar):** Menu de navegação simplificado (Home, Produtos, Contato) integrado com barra de pesquisa flutuante, área de login do cliente e contador dinâmico na sacola de compras.
2. **Hero Banner Dinâmico:** Seção de abertura com carrossel contendo imagens em alta definição e os quatro pilares institucionais da marca em formato de tópicos visuais rápidos.
3. **Vitrine de Produtos em Destaque:** Carrossel interativo (`Shadcn Carousel`) com navegação por setas laterais apresentando cards completos contendo:
   * Tag de identificação (`★ Destaque`)
   * Imagem em alta resolução com fundo transparente
   * Nome e descrição detalhada do produto
   * Preço formatado em moeda local (BRL)
   * Botão de ação direta de compra (`Comprar`) e botão de lista de desejos (Favoritos ♥).
4. **Faixa de Benefícios (Trust Badges):** Selos institucionais estrategicamente posicionados antes do rodapé para aumentar a conversão:
   * **Materiais Premium:** Selecionados com carinho.
   * **Pagamento Seguro:** Ambiente 100% protegido.
   * **Entrega para todo o Brasil:** Frete rápido e rastreável.
   * **Atendimento Humano:** Equipe pronta para ajudar.
5. **Rodapé (Footer):** Espaço minimalista reafirmando o slogan da marca: *"Pelúcias feitas para abraçar, colecionar e criar memórias especiais."*
